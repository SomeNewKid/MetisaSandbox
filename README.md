# Metisa Sandbox

Metisa Sandbox is a Python CLI application.

## Development

Set up the local development environment:

```powershell
.\scripts\setup-dev.ps1
```

Run formatting, linting, type checking, and tests:

```powershell
.\scripts\check.ps1
```

Run the CLI locally:

```powershell
python -m metisa_sandbox "PROMPT-001"
```
